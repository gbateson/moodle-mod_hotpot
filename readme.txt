========================================
The HotPot activity module for Moodle
========================================

HotPot lets teachers use Hot Potatoes (versions 6 and 7), TexToys, Xerte,
iSpring and Qedoc exercises as Moodle activities, with scores saved to the
Moodle gradebook.

For full details, including installation instructions, see README.md
or https://github.com/gbateson/moodle-mod_hotpot

Downloads:
  - https://moodle.org/plugins/mod_hotpot
  - https://github.com/gbateson/moodle-mod_hotpot

To install:
  1. Unzip the zip file, and rename the folder to "hotpot".
  2. Put the "hotpot" folder in the "mod" folder of your Moodle site,
     (in Moodle 5.1 and later, this is "public/mod").
  3. Log in to Moodle as an administrator, and go to:
     Site administration > Notifications

The HotPot question import format, which imports Hot Potatoes exercises
into the Moodle question bank, is a separate plugin:
  - https://moodle.org/plugins/qformat_hotpot
